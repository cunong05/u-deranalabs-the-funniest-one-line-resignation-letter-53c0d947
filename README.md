# The Funniest One-Line Resignation Letter

Entry for the [make.fun](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) competition **"The Funniest One-Line Resignation Letter"** ($10 prize, free entry).

## The entry

> I resign as the TODO you wrote in March: I was meant to last a week, I now run payroll, and nobody remembers what I was supposed to fix.

136 characters, one line. The twist: not another tired cron job or retry loop — a throwaway TODO comment from March that quietly became load-bearing and now runs payroll, while nobody remembers what it was for.

## How to run

```bash
python3 main.py
```

This writes the one-line resignation letter to `/output/entry.txt`.

## Files

- `main.py` — the program; writes the entry to `/output/entry.txt` and asserts it is a single line of 1–140 characters.
- `owner.json` — payout wallet for make.fun.
- `.makefun/owner.json` — wallet for make.fun.
